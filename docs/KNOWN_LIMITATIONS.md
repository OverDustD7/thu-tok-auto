# 0.3.24 已知限制

更新日期：2026-10-09。

1. **真实站点的自动续期仍需验收。** 回归测试覆盖会话交接、指纹载体编排与定时器契约，
   但不能据此保证清华站点接受无窗口浏览器生成的指纹，也不能保证服务端会话持续有效。
   首次登录后，应观察一次自然 Auto 运行是否使令牌 `exp` 前进。
2. **运行环境。** 要求 Node.js >= 22；当前宿主契约按 DSH 0.2.0-rc.2 核对。
   浏览器发现和进程树清理主要面向 Windows Edge/Chrome，未完成跨平台真机验收。
3. **更新需要重启 DSH。** 页面 F5 只刷新前端，不能替换宿主已经载入的核心逻辑。
4. **侧栏依赖宿主 DOM。** 宿主改动底部容器或按钮结构时可能无法挂载；插件会继续尝试。
   隔离预览不能替代所有宿主主题、移动端与其他插件组合下的验收。
5. **会话和时间由站点决定。** 6 小时令牌寿命和约 45 分钟可重放会话来自历史观察。
   时钟偏差会影响本地剩余寿命显示；校验通过也不能保证令牌以后不被吊销。
6. **校外 WebVPN 尚未支持。** 本版没有改变默认 MadModel 地址，没有安装本地代理或守护进程。
   GitHub PR #1–#3 独立保留，等待维护者决定。
7. **清理可能拒绝执行。** 无法读取进程表、身份不匹配、启动记录缺失或 pid 已被回收时，
   插件不能确认浏览器归属，会保留残留并报告原因。`stop-owned.js --dry-run` 可查看记录。
8. **身份读取失败的提示仍不够具体。** 手动登录捕获可能等满约 60 秒后显示登录等待超时，
   实际原因也可能是没有取得可核验的浏览器身份。
9. **本地状态包含会话材料。** `%USERPROFILE%\.dsh\madmodel\state.json` 与浏览器 profile
   应按登录凭据保护，不要提交到 GitHub、放进共享目录或附到公开 issue。
10. **模型与网关上限会变化。** 模型列表来自站点；1M 上下文配置沿用既有结果，
    本次发布整理没有重新进行长上下文压测。
