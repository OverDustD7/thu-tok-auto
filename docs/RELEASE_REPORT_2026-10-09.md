# thu-tok-auto 0.3.24 发布整理报告

日期：2026-10-09。范围：整理并发布现有本地新版，GitHub PR #1、#2、#3 留待维护者决定。

## 发布内容

以远端 0.3.6 为基线，汇总本地 0.3.24 的核心、宿主适配、UI、浏览器归属与会话恢复改动。
详细行为见 [CHANGELOG](../CHANGELOG.md)。本轮发布整理没有重新实现续期算法，
没有引入 WebVPN、本地代理、后台守护进程，也没有合并待审 PR。

## 本轮整理修改

- README 标明当前版本并补齐可公开访问的版本记录、限制和发布报告入口。
- 修正时间说明：签发服务时钟领先本地时，按本地时间计算会高估服务端剩余寿命。
- 修正浏览器清理说明：当前支持核验启动证据后的进程树回退，不再声称完全没有 `taskkill`。
- 澄清会话 cookie 的保存和恢复语义，删除手动过滤 YAML 凭据字符的建议。
- 测试数量更新为 213；语法门禁补上 `carrier-profile.js` 和 `stop-owned.js`。
- npm 白名单加入 CHANGELOG 和当前已知限制；本机浏览器 profile、生成的诊断输出与
  含本机运行细节的历史审计笔记保留在本地，不纳入发布提交。

## 验证与验收边界

- `npm run check`：结构门禁通过；新增模块语法检查随最终打包执行。
- `node --test --test-reporter=dot test/*.test.mjs`：213 项通过。
- 受限网络沙箱下最初有 5 项回环 HTTP 用例失败；允许本机网络后同一测试集全部通过，
  因此未为沙箱限制修改生产逻辑或弱化断言。
- 正式打包使用 npm `prepack` 再执行结构检查与全部回归，随后核对文件白名单。
- 本轮未操作真实清华登录、生产凭据或正在运行的 DSH；真实站点的自然 Auto 与指纹验收
  仍是明确的未验证项，见 [已知限制](./KNOWN_LIMITATIONS.md)。
